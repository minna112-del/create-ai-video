# Golapi Shop — প্রকাশিত URL তালিকা

সব URL একই `golapishop.online` deploy এবং একই repository থেকে পরিচালিত হয়। Staff URL-গুলো direct open করলেও Firebase Auth, active staff profile, role এবং permission matrix যাচাই হয়।

## Customer ও Driver

| অংশ | URL |
|---|---|
| Customer website / Customer APK | `https://www.golapishop.online/` |
| Customer account | `https://www.golapishop.online/account` |
| Customer orders | `https://www.golapishop.online/myorders` |
| Custom Bazar | `https://www.golapishop.online/custom-bazar` |
| Medical service | `https://www.golapishop.online/medical` |
| Driver web app / Driver APK | `https://www.golapishop.online/driver/` |
